# variantCell: Single-Cell SNP Analysis for Transplant Studies

A tool for analyzing single-cell SNP data with focus on organ
transplant. variantCell processes CellSNP and Vireo output to identify,
characterize, and visualize SNPs at cellular resolution, enabling
researchers to distinguish donor from recipient cells and quantify SNPs
that may influence transplant outcomes.

## Core Features

- Processing CellSNP and Vireo output data

- SNP identification and characterization across cell types

- Differential SNP analysis with rs# identifier support

- Visualization of SNP distributions and patterns

- Integration with single-cell metadata

- VCF-based rs# annotation from reference databases
